# Quantum Terrain

Unity terrain generated by quantum interference, simulated with Qiskit Aer. A
fractal spectrum passes through entangling phase gates and a QFT on each axis,
and the measurement probabilities become the heightmap.

The `--entangle` setting is the main demo control: at 0 the map is an artificial
grid, and as it rises towards 1 the grid dissolves into natural landforms.

## Layout

- `python/` generator and tests
- `baked/` heightmaps written by the generator (`.r16`, `.png`, `.json`)
- `unity/` Unity 2022.3.44f1 project

## Generate a heightmap

```
.venv\Scripts\python python\generate_terrain.py --seed 7 --entangle 1.0
```

Options: `--qubits-per-axis`, `--beta` (higher is smoother), `--detail`, `--gamma`, `--shots`
(sample from measurements instead of exact probabilities), `--name`, `--out`.

## Import into Unity

Open `unity/` in Unity Hub, then choose **Quantum Terrain > Import Baked Heightmap**
and pick a `.r16` file from `baked/`.

Every import or live update also colours the terrain by height and slope. The
thresholds are at the top of `QuantumTerrainSplat.cs`.

## Live controls

Start the server and leave it running:

```
.venv\Scripts\python python\terrain_server.py
```

Then choose **Quantum Terrain > Live Controls** in Unity. Moving a slider
regenerates the terrain. Turn on **Sample measurements** to build the map from
a finite number of shots instead of exact probabilities.

**Sweep Entanglement** animates from a mirrored, axis-aligned map to natural
landforms. **Sweep Measurements** animates from 10^3 to 10^9 shots, from scattered
spikes to the exact terrain. The preset buttons jump to good starting points.

A seed keeps its landforms at every resolution. `--beta` sets how smooth the
large landforms are, and `--detail` (0 to 1, default 0.75) adds small-scale
texture on top without moving them. With detail on, 512x512 shows texture that
256x256 can't, so it's worth the extra qubits for close-up views.

## Presentation view

Choose **Quantum Terrain > Set Up Presentation View** once per scene, then press
Play. The camera orbits the terrain, and a panel shows the entanglement, qubits,
measurements and entropy with a short caption. Keep Live Controls open and the
server running, since the panel updates whenever a new terrain arrives. Turn on
**Play Maximized** in the Game view for a clean screen.

## How the frames are made

Each server result is a real circuit output. Unity glides between them with a
short height blend, so the frames in between are interpolated for display.

## Quantum vs classical

```
.venv\Scripts\python python\compare_classical.py
```

Compares 200 quantum terrains with two classical generators: one using the same
spectrum with independent random phases, and standard fractal noise (fBm). It
reports speed, eight terrain statistics, and whether a classifier can tell the
sets apart. A zero-entanglement set and a second classical batch act as positive
and negative controls.

On 2 Nov 2026, fully entangled quantum terrain was indistinguishable from both
(46.5% and 53.0%, where 50% is chance) and about 17 times slower to generate.

## Tests

```
.venv\Scripts\python -m pytest python
```

The tests compare the simulator against an independent NumPy calculation. Keep
`optimization_level=1` in `simulate()`: level 2 and above silently reorder the
qubits of a saved statevector, which turns the terrain into noise.
