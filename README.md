# Quantum Terrain

Unity terrain generated by quantum interference, simulated with Qiskit Aer. A
fractal spectrum passes through entangling phase gates and a QFT on each axis,
and the measurement probabilities become the heightmap.

The `--entangle` setting is the main demo control: at 0 the map is an artificial
grid, and as it rises towards 1 the grid dissolves into natural landforms.

## Layout

- `python/` generator and tests
- `baked/` heightmaps written by the generator (`.r16`, `.png`, `.json`)
- `unity/` Unity 2022.3.44f1 project

## Generate a heightmap

```
.venv\Scripts\python python\generate_terrain.py --seed 7 --entangle 1.0
```

Options: `--qubits-per-axis`, `--beta` (higher is smoother), `--gamma`, `--shots`
(sample from measurements instead of exact probabilities), `--name`, `--out`.

## Import into Unity

Open `unity/` in Unity Hub, then choose **Quantum Terrain > Import Baked Heightmap**
and pick a `.r16` file from `baked/`.

Every import or live update also colours the terrain by height and slope. The
thresholds are at the top of `QuantumTerrainSplat.cs`.

## Live controls

Start the server and leave it running:

```
.venv\Scripts\python python\terrain_server.py
```

Then choose **Quantum Terrain > Live Controls** in Unity. Moving a slider
regenerates the terrain. Turn on **Sample measurements** to build the map from
a finite number of shots instead of exact probabilities.

## Tests

```
.venv\Scripts\python -m pytest python
```

The tests compare the simulator against an independent NumPy calculation. Keep
`optimization_level=1` in `simulate()`: level 2 and above silently reorder the
qubits of a saved statevector, which turns the terrain into noise.
